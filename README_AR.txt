دليلك للسادس العلمي — نسخة أولية قابلة للتثبيت كـ PWA

محتويات النسخة:
- جدول يومي تفاعلي لأربع جلسات
- حفظ إنجاز الجلسات محلياً على الجهاز/المتصفح
- بطاقات المواد السبع
- اختبار تجريبي مع تصحيح فوري
- زر يفتح ChatGPT مع طلب المدرّس الذكي
- دعم أساسيات PWA والعمل دون اتصال بعد أول تحميل (عند الاستضافة عبر HTTPS)

مهم:
هذه ليست تطبيقاً رسمياً من وزارة التربية، ولا تتضمن كل دروس المنهج أو اتصال API مستقلاً.
بيانات الإنجاز محفوظة محلياً فقط، وقد لا تنتقل إلى جهاز آخر.
رابط المدرّس يفتح ChatGPT؛ يتطلب الاتصال بالإنترنت وتسجيل الدخول حسب إعدادات المستخدم.

طريقة التثبيت على iPhone:
1. ارفع الملفات الثلاثة (index.html, manifest.json, service-worker.js) إلى استضافة HTTPS مثل GitHub Pages.
2. افتح رابط index.html في Safari على الآيفون.
3. اضغط زر المشاركة (المربع مع السهم للأعلى).
4. اختر Add to Home Screen / إضافة إلى الشاشة الرئيسية.
5. فعّل Open as Web App إن ظهر الخيار، ثم اضغط Add.

لا يمكن تثبيت PWA من ملف ZIP مباشرة؛ يلزم رابط HTTPS. يمكن أيضاً فتح index.html للتجربة على كمبيوتر، لكن بعض خصائص التثبيت والعمل دون اتصال تتطلب استضافة.

الخطوة التالية لتطوير نسخة كاملة:
- اعتماد طبعة كتب 2026–2027 وإضافة فهرس كل مادة بدقة.
- إضافة قاعدة بيانات ومزامنة إنجاز.
- إن رغبت بمدرس ذكاء اصطناعي داخل التطبيق نفسه، يلزم خادم آمن ومفتاح API؛ لا تضع مفتاح API في ملفات الواجهة.
